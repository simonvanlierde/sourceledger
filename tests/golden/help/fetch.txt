usage: sourceledger fetch [-h] [--manifest PATH] [--only ID] [--dry-run]
                          [--json]

Download every implemented source and log it.

options:
  -h, --help       show this help message and exit
  --manifest PATH  the manifest to read (default: sources.toml)
  --only ID        only this source (repeatable)
  --dry-run        say what would happen, and write nothing
  --json           print one JSON object instead of text
