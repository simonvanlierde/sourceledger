# Arimo

`arimo.woff2` contains the full variable Arimo font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/arimo), distributed under
[the SIL Open Font License](OFL.txt). The site serves it locally.

The WOFF2 encoding preserves the original glyphs, outlines, widths and variable weights;
it is not a subset. FontTools 4.67.0 encoded the source TTF with Brotli font compression.
Source TTF SHA-256: `e43898b143ec826ac8cb4034816458a7047fbe0836558de2a1f8c6223ae3e0ca`.
